用户运营私域管理系统 (Beauty-SCRM)

这是一个基于 AI 工具（WorkBuddy）搭建的 C 端私域客户管理系统，将我在校园美妆项目的操盘逻辑，沉淀为可视化的运营工具。

## 🌟 在线体验
👉 [点击这里立即体验系统](https://beauty-scrm.app.workbuddy.host/)

## 📌 核心功能
- **客户管理**：基础信息、标签、来源渠道沉淀
- **RFM 分层**：基于消费频次和金额，将用户分为高价值、活跃、沉睡、流失四层
- **跟进 SOP**：一键跟进记录，逾期自动提醒
- **社群运营**：群组管理、群发助手、互动记录
- **自动化洞察**：高价值流失预警、活动复盘看板
